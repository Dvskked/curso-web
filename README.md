Este curso es una **aplicación web interactiva** que funciona directamente en tu navegador. No necesitas instalar nada. Al abrir el archivo `index.html`, accederás a una interfaz elegante con:

|:---:|:---|
| 🌗 **Tema Claro / Oscuro** | Alterna entre ambos temas con un solo clic. Los estilos se guardan automáticamente en `localStorage`. |
| 📱 **Totalmente Responsive** | Se adapta a pantallas de escritorio, tablets y móviles con un diseño mobile-first. |
| 📑 **Navegación por Módulos** | Explora los 10 módulos del curso con sus lecciones expandibles. |
| 🔍 **Barra de Búsqueda** | Encuentra cualquier tema o lección en tiempo real. |
| 📌 **Barra de Progreso** | Visualiza tu avance a medida que completas las lecciones. |

| ⚡ **Carga Instantánea** | Sin frameworks, sin compiladores. Solo archivos estáticos puros. |

```

├── 📄 index.html              ← Página principal del curso
```

| Archivo | Tamaño aprox. | Descripción |
|:---|:---:|:---|
| `index.html` | ~150 KB | Estructura HTML completa con todos los módulos, lecciones y ejemplos |

> 📊 **Total:** ~310 KB de código puro. Sin frameworks, sin dependencias externas, sin complicaciones.


### 4. Haz tus cambios

```bash

git push origin feature/nueva-funcionalidad
```

```

3. Selecciona tu rama
4. Escribe un título descriptivo
```
