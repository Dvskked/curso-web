Modulo 1: Fundamentos de HTML

En este modulo aprenderas los cimientos de toda pagina web. HTML es el lenguaje que estructura el contenido y es el primer paso para convertirte en desarrollador web.

1.1 Que es HTML y como funciona

HTML significa HyperText Markup Language (Lenguaje de Marcado de HiperTexto). Es el lenguaje estandar para crear paginas web. HTML no es un lenguaje de programacion, sino de marcado: usa "etiquetas" (tags) para definir la estructura y el significado del contenido.

Elementos HTML

Un elemento HTML esta compuesto por una etiqueta de apertura, contenido y una etiqueta de cierre: 

<!-- Elemento completo: etiqueta + contenido + cierre -->
<p>Este es un parrafo.</p>

<!-- Elemento con atributo -->
<a href="https://ejemplo.com">Enlace</a>

<!-- Elemento vacio (sin contenido ni cierre) -->
<img src="foto.jpg" alt="Descripcion">
<br>
<hr>

Atributos HTML

Los atributos proporcionan informacion adicional sobre los elementos. Se colocan en la etiqueta de apertura y siguen la sintaxis nombre="valor": 

<!-- Atributo comun: class para CSS -->
<div class="contenedor">...</div>

<!-- Atributo id: identificador unico -->
<section id="principal">...</section>

<!-- Atributo booleano (se escribe solo el nombre) -->
<input required disabled>

<!-- Atributo data-*: datos personalizados -->
<article data-category="tecnologia">...</article>

1.2 DOCTYPE y estructura del documento

Todo documento HTML5 comienza con la declaracion <!DOCTYPE html>, que le indica al navegador que debe interpretar el documento como HTML5. 

<!-- Declaracion del tipo de documento -->
<!DOCTYPE html>

<!-- Etiqueta raiz con idioma -->
<html lang="es">

  <!-- Contenedor de metadatos -->
  <head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>Mi Pagina</title>
  </head>

  <!-- Contenido visible -->
  <body>
    <h1>Mi primera pagina</h1>
  </body>

</html>
Nota: En HTML5 la declaracion DOCTYPE no distingue entre mayusculas y minusculas. Puedes escribir <!doctype html> o <!DOCTYPE HTML>.

1.3 El elemento head y metaetiquetas

El elemento <head> contiene metadatos sobre el documento que no se muestran directamente en la pagina pero son esenciales para su correcto funcionamiento.

Metaetiquetas esenciales

<head>
  <!-- Codificacion de caracteres -->
  <meta charset="UTF-8">

  <!-- Viewport para diseno responsivo -->
  <meta name="viewport"
        content="width=device-width, initial-scale=1.0">

  <!-- Titulo en la pestana del navegador -->
  <title>Mi Pagina</title>

  <!-- Descripcion para motores de busqueda -->
  <meta name="description"
        content="Descripcion de mi pagina web">

  <!-- Favicon -->
  <link rel="icon" href="favicon.ico">

  <!-- Hoja de estilos -->
  <link rel="stylesheet" href="styles.css">
</head>

Open Graph y Redes Sociales

<!-- Open Graph para Facebook, LinkedIn, etc. -->
<meta property="og:title" content="Titulo de la pagina">
<meta property="og:description" content="Descripcion">
<meta property="og:image" content="https://ejemplo.com/imagen.jpg">
<meta property="og:url" content="https://ejemplo.com">

<!-- Twitter Card -->
<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:title" content="Titulo">
<meta name="twitter:description" content="Descripcion">

1.4 Jerarquia de titulos H1 a H6

Los titulos van desde <h1> (el mas importante) hasta <h6> (el menos importante). Cada pagina debe tener un solo h1 y los demas se usan en orden jerarquico.

Titulo H1 - El principal

Titulo H2 - Seccion

Titulo H3 - Subseccion

Titulo H4 - Grupo

Titulo H5 - Subgrupo
Titulo H6 - Menor
<h1>Titulo Principal de la Pagina</h1>
<h2>Titulo de Seccion</h2>
<h3>Titulo de Subseccion</h3>
<h4>Titulo de Grupo</h4>
<h5>Titulo de Subgrupo</h5>
<h6>Titulo de menor importancia</h6>
Importante: Nunca saltes niveles de jerarquia (por ejemplo, de h2 a h4 sin un h3 intermedio). Esto afecta la accesibilidad y el SEO.

1.5 Parrafos, saltos y formato de texto

Parrafos

El parrafo es el bloque basico de texto. El navegador agrega espacio automaticamente entre parrafos. 

<p>Este es mi primer parrafo en HTML.</p>
<p>Este es el segundo parrafo. Se separa automaticamente.</p>

<!-- Salto de linea -->
<p>Primera linea<br>Segunda linea</p>

<!-- Linea horizontal -->
<hr>

Formato de texto inline

<p>
  <strong>Texto en negrita semantica</strong>
  <em>Texto en italica semantica</em>
  <b>Negrita visual (sin enfasis semantico)</b>
  <i>Italica visual</i>
  <u>Texto subrayado</u>
  <s>Texto tachado</s>
  <mark>Texto resaltado</mark>
  <small>Texto pequenio</small>
  <sub>Subindice (H<sub>2</sub>O)</sub>
  <sup>Superindice (E=mc<sup>2</sup>)</sup>
  <code>Codigo en linea</code>
  <abbr title="HyperText Markup Language">HTML</abbr>
</p>

Bloque de codigo preformateado

<pre><code>
  function saludar(nombre) {
    console.log(`Hola, ${nombre}!`);
  }
</code></pre>

1.6 Listas: ordenadas, desordenadas y de definicion

HTML soporta tres tipos principales de listas:

Lista Ordenada

  1. Primer elemento
  2. Segundo elemento
  3. Tercer elemento

Lista Desordenada

  • Item A
  • Item B
  • Item C

Lista de Definicion

HTML
Lenguaje de marcado para estructura
CSS
Lenguaje de estilos para diseno
<!-- Lista Ordenada -->
<ol>
  <li>Primero</li>
  <li>Segundo</li>
  <li>Tercero</li>
</ol>

<!-- Lista Ordenada con tipo -->
<ol type="A">
  <li>Opcion A</li>
  <li>Opcion B</li>
</ol>

<!-- Lista Desordenada -->
<ul>
  <li>Manzana</li>
  <li>Pera</li>
  <li>Naranja</li>
</ul>

<!-- Lista de Definicion -->
<dl>
  <dt>HTML</dt>
  <dd>HyperText Markup Language</dd>
  <dt>CSS</dt>
  <dd>Cascading Style Sheets</dd>
</dl>

1.7 Enlaces y navegacion

Los enlaces (<a>) son la base de la navegacion web. Permiten conectar paginas entre si. 

<!-- Enlace basico -->
<a href="https://ejemplo.com">Visitar ejemplo</a>

<!-- Abrir en nueva pestana -->
<a href="https://ejemplo.com"
   target="_blank"
   rel="noopener noreferrer">
  Externo
</a>

<!-- Enlace de correo -->
<a href="mailto:correo@ejemplo.com">Enviar email</a>

<!-- Enlace de telefono -->
<a href="tel:+34600000000">Llamar</a>

<!-- Descarga de archivo -->
<a href="archivo.pdf" download>Descargar PDF</a>

<!-- Ancla interna -->
<a href="#seccion-contacto">Ir a Contacto</a>
...
<section id="seccion-contacto">...</section>

1.8 Imagenes, audio y video

Imagenes con img y picture

<!-- Imagen basica con texto alternativo -->
<img
  src="foto.webp"
  alt="Paisaje montanoso al atardecer"
  width="800"
  height="600"
  loading="lazy">

<!-- Imagen responsiva con picture -->
<picture>
  <source media="(min-width: 800px)"
          srcset="imagen-grande.webp">
  <source media="(min-width: 400px)"
          srcset="imagen-mediana.webp">
  <img src="imagen-pequena.webp"
       alt="Descripcion fallback">
</picture>

<!-- Imagen con figura y caption -->
<figure>
  <img src="grafico.png" alt="Grafico de ventas">
  <figcaption>Ventas trimestrales 2026</figcaption>
</figure>

Audio y Video

<!-- Audio -->
<audio controls preload="metadata">
  <source src="audio.mp3" type="audio/mpeg">
  <source src="audio.ogg" type="audio/ogg">
  <p>Tu navegador no soporta audio.
    <a href="audio.mp3">Descargar</a>
  </p>
</audio>

<!-- Video -->
<video controls width="720"
       poster="miniatura.jpg"
       preload="metadata">
  <source src="video.mp4" type="video/mp4">
  <source src="video.webm" type="video/webm">
  <track kind="subtitles" src="subs.vtt"
         srclang="es" label="Espanol" default>
  <p>Tu navegador no soporta video HTML5.</p>
</video>
