Modulo 1: Fundamentos de HTML

En este modulo aprenderas los cimientos de toda pagina web. HTML es el lenguaje que estructura el contenido y es el primer paso para convertirte en desarrollador web.

1.1 Que es HTML y como funciona

HTML significa HyperText Markup Language (Lenguaje de Marcado de HiperTexto). Es el lenguaje estandar para crear paginas web. HTML no es un lenguaje de programacion, sino de marcado: usa "etiquetas" (tags) para definir la estructura y el significado del contenido.

Elementos HTML

Un elemento HTML esta compuesto por una etiqueta de apertura, contenido y una etiqueta de cierre: 

<!-- Elemento completo: etiqueta + contenido + cierre -->
<p>Este es un parrafo.</p>

<!-- Elemento con atributo -->
<a href="https://ejemplo.com">Enlace</a>

<!-- Elemento vacio (sin contenido ni cierre) -->
<img src="foto.jpg" alt="Descripcion">
<br>
<hr>

Atributos HTML

Los atributos proporcionan informacion adicional sobre los elementos. Se colocan en la etiqueta de apertura y siguen la sintaxis nombre="valor": 

<!-- Atributo comun: class para CSS -->
<div class="contenedor">...</div>

<!-- Atributo id: identificador unico -->
<section id="principal">...</section>

<!-- Atributo booleano (se escribe solo el nombre) -->
<input required disabled>

<!-- Atributo data-*: datos personalizados -->
<article data-category="tecnologia">...</article>

1.2 DOCTYPE y estructura del documento

Todo documento HTML5 comienza con la declaracion <!DOCTYPE html>, que le indica al navegador que debe interpretar el documento como HTML5. 

<!-- Declaracion del tipo de documento -->
<!DOCTYPE html>

<!-- Etiqueta raiz con idioma -->
<html lang="es">

  <!-- Contenedor de metadatos -->
  <head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>Mi Pagina</title>
  </head>

  <!-- Contenido visible -->
  <body>
    <h1>Mi primera pagina</h1>
  </body>

</html>
Nota: En HTML5 la declaracion DOCTYPE no distingue entre mayusculas y minusculas. Puedes escribir <!doctype html> o <!DOCTYPE HTML>.

1.3 El elemento head y metaetiquetas

El elemento <head> contiene metadatos sobre el documento que no se muestran directamente en la pagina pero son esenciales para su correcto funcionamiento.

Metaetiquetas esenciales

<head>
  <!-- Codificacion de caracteres -->
  <meta charset="UTF-8">

  <!-- Viewport para diseno responsivo -->
  <meta name="viewport"
        content="width=device-width, initial-scale=1.0">

  <!-- Titulo en la pestana del navegador -->
  <title>Mi Pagina</title>

  <!-- Descripcion para motores de busqueda -->
  <meta name="description"
        content="Descripcion de mi pagina web">

  <!-- Favicon -->
  <link rel="icon" href="favicon.ico">

  <!-- Hoja de estilos -->
  <link rel="stylesheet" href="styles.css">
</head>

Open Graph y Redes Sociales

<!-- Open Graph para Facebook, LinkedIn, etc. -->
<meta property="og:title" content="Titulo de la pagina">
<meta property="og:description" content="Descripcion">
<meta property="og:image" content="https://ejemplo.com/imagen.jpg">
<meta property="og:url" content="https://ejemplo.com">

<!-- Twitter Card -->
<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:title" content="Titulo">
<meta name="twitter:description" content="Descripcion">

1.4 Jerarquia de titulos H1 a H6

Los titulos van desde <h1> (el mas importante) hasta <h6> (el menos importante). Cada pagina debe tener un solo h1 y los demas se usan en orden jerarquico.

Titulo H1 - El principal

Titulo H2 - Seccion

Titulo H3 - Subseccion

Titulo H4 - Grupo

Titulo H5 - Subgrupo
Titulo H6 - Menor
<h1>Titulo Principal de la Pagina</h1>
<h2>Titulo de Seccion</h2>
<h3>Titulo de Subseccion</h3>
<h4>Titulo de Grupo</h4>
<h5>Titulo de Subgrupo</h5>
<h6>Titulo de menor importancia</h6>
Importante: Nunca saltes niveles de jerarquia (por ejemplo, de h2 a h4 sin un h3 intermedio). Esto afecta la accesibilidad y el SEO.

1.5 Parrafos, saltos y formato de texto

Parrafos

El parrafo es el bloque basico de texto. El navegador agrega espacio automaticamente entre parrafos. 

<p>Este es mi primer parrafo en HTML.</p>
<p>Este es el segundo parrafo. Se separa automaticamente.</p>

<!-- Salto de linea -->
<p>Primera linea<br>Segunda linea</p>

<!-- Linea horizontal -->
<hr>

Formato de texto inline

<p>
  <strong>Texto en negrita semantica</strong>
  <em>Texto en italica semantica</em>
  <b>Negrita visual (sin enfasis semantico)</b>
  <i>Italica visual</i>
  <u>Texto subrayado</u>
  <s>Texto tachado</s>
  <mark>Texto resaltado</mark>
  <small>Texto pequenio</small>
  <sub>Subindice (H<sub>2</sub>O)</sub>
  <sup>Superindice (E=mc<sup>2</sup>)</sup>
  <code>Codigo en linea</code>
  <abbr title="HyperText Markup Language">HTML</abbr>
</p>

Bloque de codigo preformateado

<pre><code>
  function saludar(nombre) {
    console.log(`Hola, ${nombre}!`);
  }
</code></pre>

Modulo 2: HTML Semantico y Accesibilidad

Aprende a usar los elementos correctos para cada tarea. El HTML semantico mejora la accesibilidad, el SEO y la mantenibilidad de tu codigo.

2.1 Por que no abusar de los divs

Usar <div> para todo es un error comun. Los divs no transmiten ningun significado al navegador ni a los lectores de pantalla.

✗ Codigo Malo (div soup)

<div class="header">
  <div class="logo">Logo</div>
  <div class="nav">
    <div class="link">Inicio</div>
  </div>
</div>
<div class="content">
  <div class="title">Titulo</div>
  <div class="text">Texto</div>
</div>

✓ Codigo Bueno (semantico)

<header>
  <img src="logo.svg" alt="Logo">
  <nav>
    <a href="/">Inicio</a>
  </nav>
</header>
<main>
  <h1>Titulo</h1>
  <p>Texto</p>
</main>

2.2 Elementos semanticos de estructura

HTML5 ofrece elementos semanticos que definen la estructura de la pagina:

<header>

Contenido introductorio o de navegacion. Se puede usar varias veces (una por seccion).

<nav>

Grupo de enlaces de navegacion principal o secundaria.

<main>

Contenido principal unico de la pagina. Solo uno por documento.

<article>

Contenido independiente y autocontenido (post, noticia, tweet).

<section>

Agrupacion tematica de contenido. Usualmente con un titulo.

<aside>

Contenido tangencialmente relacionado (sidebars, publicidad).

<footer>

Pie de pagina o de seccion. Copyright, enlaces, etc.

<figure>

Contenido ilustrativo con <figcaption> opcional.

2.3 Estructura correcta completa

Aqui tienes la estructura semantica completa de una pagina web:

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <meta name="viewport"
        content="width=device-width, initial-scale=1.0">
  <title>Mi Sitio</title>
</head>
<body>

  <header role="banner">
    <a href="/"><img src="logo.svg" alt="Inicio"></a>
    <nav aria-label="Principal">
      <ul>
        <li><a href="#inicio">Inicio</a></li>
        <li><a href="#acerca">Acerca</a></li>
        <li><a href="#contacto">Contacto</a></li>
      </ul>
    </nav>
  </header>

  <main id="contenido-principal">
    <article>
      <header>
        <h1>Titulo del Article</h1>
        <p><time datetime="2026-01-15">15 enero 2026</time></p>
      </header>
      <p>Contenido del articulo...</p>
      <footer>
        <p>Autor: Tu Nombre</p>
      </footer>
    </article>

    <aside aria-label="Contenido relacionado">
      <h2>Relacionado</h2>
      <p>Links y recursos adicionales</p>
    </aside>
  </main>

  <footer role="contentinfo">
    <p>&copy; 2026 Mi Sitio</p>
    <nav aria-label="Legal">
      <a href="#privacidad">Privacidad</a>
    </nav>
  </footer>

</body>
</html>

2.4 Atributos ARIA

ARIA (Accessible Rich Internet Applications) ayuda a los lectores de pantalla a entender la interfaz cuando el HTML semantico no es suficiente. 

<!-- aria-label: nombre accesible -->
<button aria-label="Cerrar menu">
  <span aria-hidden="true">&times;</span>
</button>

<!-- aria-labelledby: referencia a otro elemento -->
<div aria-labelledby="titulo-seccion">
  <h2 id="titulo-seccion">Seccion</h2>
</div>

<!-- aria-describedby: descripcion adicional -->
<input aria-describedby="clave-ayuda">
<p id="clave-ayuda">Minimo 8 caracteres</p>

<!-- aria-expanded: estado colapsable -->
<button aria-expanded="false"
        aria-controls="menu">Menu</button>

<!-- role: define la funcion -->
<div role="alert">Error de conexion</div>
<div role="status" aria-live="polite">
  3 resultados encontrados
</div>

<!-- aria-hidden: ocultar de lectores de pantalla -->
<span aria-hidden="true">☼</span>

Las tablas se usan solo para datos tabulares, nunca para diseno. Usa <caption>, <thead>, <tbody>, <tfoot> y scope.

    </tr>

      <th scope="row">HTML</th>
      <td>9:00</td>

    </tr>
    <tr>
      <th scope="row">CSS</th>
      <td>10:00</td>

2.7 Enfoque: NO abusar de divs (9 Reglas)

  1. Usa <header> en lugar de <div class="header">
  2. Usa <nav> en lugar de <div class="nav">
  3. Usa <main> en lugar de <div class="main">
  4. Usa <article> para contenido independiente
  5. Usa <section> para agrupar contenido por tema
  6. Usa <aside> para contenido lateral
  7. Usa <footer> para pies de pagina/seccion
  8. Usa <figure> y <figcaption> para imagenes con caption
  9. Reserva <div> solo para contenedor de estilos cuando ningun elemento semantico aplica

2.8 Buenas practicas de accesibilidad

  1. Siempre incluye alt descriptivo en imagenes. Si es decorativa, usa alt=""
  2. Usa un solo <h1> por pagina y mantén la jerarquia de titulos
  3. Los enlaces deben tener texto descriptivo, nunca "haz clic aqui"
  4. Usa <label> asociado a cada campo de formulario
  5. Maintene un orden de tabulacion logico con tabindex="0" cuando sea necesario
  6. Verifica el contraste de colores (minimo 4.5:1 para texto normal)
  7. Proporciona indicadores de foco visibles para navegacion por teclado
  8. Usa ARIA solo cuando el HTML semantico no es suficiente

Modulo 3: Formularios y Validacion

Los formularios son la forma principal de interaccion con el usuario. Aprende a crear formularios accesibles, validos y funcionales.

<!-- required: campo obligatorio -->
<input type="text" required>

<!-- minlength / maxlength -->
<input type="text" minlength="3" maxlength="50">

<!-- min / max para numeros y fechas -->
<input type="number" min="0" max="10">

<!-- pattern: expresion regular -->
<input type="text"
       pattern="[A-Za-z]{3,20}"
       title="Solo letras, 3 a 20 caracteres">

<!-- placeholder (no sustituye al label) -->
<input type="text" placeholder="Ej: Juan">

<!-- step: incremento -->
<input type="number" step="0.1">

  <option value="CSS">
  <option value="JavaScript">
</datalist>

<!-- Output -->

3.5 Formularios accesibles

  1. Siempre asocia <label> con for al id del input
  2. Usa <fieldset> y <legend> para agrupar campos relacionados
  3. Indica campos obligatorios con required y visualmente con *
  4. Proporciona mensajes de error con aria-describedby
  5. Usa autocomplete para ayudar al usuario a completar datos
  6. Agrupa campos de forma logica con el orden de tabulacion correcto

<div>
  <label for="email">
    Correo electronico <span aria-hidden="true">*</span>
  </label>
  <input
    type="email"
    id="email"
    name="email"
    required
    aria-describedby="email-error"
    aria-invalid="false"
    autocomplete="email">
  <p id="email-error" role="alert" hidden>
    Por favor ingresa un correo valido.
  </p>
</div>

3.7 Validacion con JavaScript

// Validacion personalizada con Constraint Validation API
const formulario = document.querySelector('.demo-form');

formulario.addEventListener('submit', (evento) => {
  evento.preventDefault();

  const campos = formulario.querySelectorAll('[required]');
  let valido = true;

  campos.forEach(campo => {

    }
  });

  if (valido) {
    console.log('Formulario valido, enviando...');

  }
});

Modulo 4: Fundamentos de CSS

CSS (Cascading Style Sheets) es el lenguaje que da vida visual a tu HTML. En este modulo aprenderas todo lo necesario para estilizar cualquier pagina web.

4.1 Que es CSS y como se aplica

CSS se puede aplicar de tres formas:

/* 1. Hoja de estilos externa (RECOMENDADO) */
<link rel="stylesheet" href="styles.css">

/* 2. Estilos internos (en el head) */
<style>
  body {
    margin: 0;
  }
</style>

/* 3. Estilos inline (EVITAR) */
<p style="color: red;">Texto rojo</p>

4.2 Sintaxis de reglas CSS

/* Selector { Propiedad: Valor; } */

/* Regla basica */
h1 {
  color: #333;
  font-size: 2rem;
  margin-bottom: 1rem;
}

/* Multiples selectores */
h1, h2, h3 {
  line-height: 1.2;

Modulo 5: Layout con Flexbox

Flexbox es un sistema de layout unidimensional que facilita alinear y distribuir espacio entre elementos de un contenedor, incluso cuando su tamanho es desconocido.

5.1 Contenedor flex y ejes

/* Activar Flexbox */
.contenedor {
  display: flex;

  /* Direccion del eje principal */
  flex-direction: row;           /* -> default */
  flex-direction: row-reverse;  /* <- */
  flex-direction: column;       /* | */
  flex-direction: column-reverse; /* ^ */

  /* Envolver items */
  flex-wrap: nowrap;    /* default */
  flex-wrap: wrap;      /* Permite saltos de linea */

  /* Espacio entre items */
  gap: 1rem;
  row-gap: 1rem;
  column-gap: 2rem;
}

/* En los items */
.item {
  flex-grow: 1;   /* Crece para llenar espacio */
  flex-shrink: 0; /* No se encoge */
  flex-basis: 200px; /* Ancho base */

  /* Shorthand */
  flex: 1 0 200px; /* grow shrink basis */
}

5.2 Alineacion con Flexbox

.contenedor {
  /* Alineacion en el eje principal */
  justify-content: flex-start;    /* Inicio */
  justify-content: flex-end;      /* Fin */
  justify-content: center;       /* Centrado */
  justify-content: space-between; /* Espacio entre */
  justify-content: space-around;  /* Espacio alrededor */
  justify-content: space-evenly;  /* Espacio uniforme */

  /* Alineacion en el eje transversal */
  align-items: stretch;     /* default */
  align-items: flex-start;
  align-items: flex-end;
  align-items: center;
  align-items: baseline;

  /* Alineacion de lineas (flex-wrap) */
  align-content: flex-start;
  align-content: center;
  align-content: space-between;

  /* Shorthand: place-items */
  place-items: center;          /* align-items + justify-items */
  place-content: center;        /* align-content + justify-content */
}

5.3 Alineacion individual

/* Alinear un item individualmente */
.item-especial {
  align-self: flex-end;
  order: -1; /* Mover al inicio (default: 0) */
}
